# map-context — Full Audit (2026-07-12)

> Companion to the Cuboid Studio system audit (`cuboid-studio/docs/SYSTEM_MAP.md`
> and `GAPS_AND_HOLES.md`). This file records what this app actually does layer
> by layer, the embed contract with Cuboid Studio, and every gap found — so any
> future session can act on it without re-discovering.

## What the analysis pipeline actually fetches (`index.js runAnalysis`)

> **2026-07-26:** all seven layers below now fetch **in parallel** (previously
> buildings → trees → OSM → registration ran serially before the parallel
> trio); ArcGIS catalog discovery is memoized per process; TABA document
> downloads run 4-wide with shorter timeouts. Wall time is now bounded by the
> slowest single layer instead of the sum.

| Layer | Source | Failure behavior |
|---|---|---|
| Geocoding | Nominatim (single endpoint, `countrycodes=il`) | **Fatal** — no fallback |
| Buildings + heights | GovMap ArcGIS → Tel Aviv GIS fallback; height gap-fill from OSM levels, else 9.6 m default | Fatal if **both** catalogs fail; layers discovered by Hebrew keyword-matching (brittle on rename) |
| Trees | Tel Aviv Open Data only | **Fatal** — and throws when no matching layer exists, i.e. outside Tel Aviv |
| Streets / transit / institutions | Overpass (4 endpoints, retries + backoff) | Fatal on total failure. **Bus routes: requested as relations but the parser only handles nodes/ways → always empty** |
| Registration blocks | Tel Aviv GIS | Graceful (empty) |
| Elevation | OpenTopoData → Open-Elevation | Graceful (N/A) |
| CBS demographics | data.gov.il CKAN, heuristic column/package matching; boundary GeoJSON up to ~200 MB — **disk-cached 30 days since 2026-07-26** (plus per-coordinate matched-area cache); locality defaults to 6900 (Tel Aviv) | Graceful (null) |
| TABA statutory plans | TLV GIS parcel → land.gov.il TabaSearch → doc downloads → Meirim polygons | Graceful (empty); index cached forever (no TTL) |
| TABA document analysis (lazy, since 2026-07-26) | `GET /taba-analysis/:plan` — mmg.zip shapefiles → land-use polygons + boundary; Xplan gap-fill; takanon Table-5 → rights. Cached per plan 30 days in `cache/taba-analysis/`. See `TABA_ANALYSIS_SCOPE.md`. | Graceful (empty low-confidence record); never in the `runAnalysis` critical path |

Dashboard: only the Map tab and the TABA tab are real; the other five tabs are
"coming soon" placeholders. Client-side SVG (Rhino) and OBJ+MTL exports exist
but only as in-browser buttons — no API exposes them.

Atlas: city or site mode (`/atlas?lat&lon&r&label`, Israel-bounds-checked,
radius clamped 100–3000); orbit/fly/walk, 25 curated landmarks, search
(EN/Hebrew), tour, minimap, day/night, `?mock=1` offline city, `?rebuild=1`;
OSM cache 1 week, built HTML cached indefinitely.

## The embed contract with Cuboid Studio

- `POST /analyze` → `{html, data}` JSON, **CORS `*`** — the cleanest machine
  hook, currently unused by Cuboid Studio.
- `POST /run` → SSE progress + final html with an injected
  `window.parent.postMessage({type:'analysis-complete', data}, '*')`.
- **BUG (P0) — FIXED 2026-07-12:** the message never reached Cuboid Studio.
  The launcher page consumes `/run` itself and renders the html into a nested
  `srcdoc` iframe (`launcher.js showDashboard`); the dashboard's
  `window.parent` is the launcher page, which had no message listener and no
  relay. Cuboid Studio's listener (`MapContextCanvas.tsx`, origin-enforced)
  sits one level higher and never fired. **Fix shipped:** the launcher page now
  relays `analysis-complete` messages (only that type, only from its own
  same-origin dashboard iframe) up to `window.parent`. Verified with a
  Playwright test reproducing the exact production nesting (foreign parent →
  launcher iframe → srcdoc dashboard): the payload arrives at the top page.
- No `X-Frame-Options`/CSP anywhere → embeddable by any origin; endpoints are
  unauthenticated (fine for demo; rate-limit/token before wide sharing).
- The picker sends the selected suggestion's lat/lon in the body but the server
  ignores them and **re-geocodes the address string** — a picked suggestion can
  resolve to a different point.
- Analysis radius is hardcoded 400 m in `index.js` CONFIG — not exposed as a
  parameter (the atlas already does this right).

## Other bugs found

1. **TABA document links never render — FIXED 2026-07-26:** pipeline stored
   `documents.takanon/tasrit/mmg`; dashboard read `documents.main/K/M` (never
   set). Now the dashboard reads the real keys, docs live in a shared
   `cache/taba-docs/` root, and the launcher serves them at `/taba-docs/`
   (works from the srcdoc dashboard iframe; CLI `file://` output still won't
   resolve these URLs).
2. **TABA plan geometry is fictional — FIXED 2026-07-26:** `plan.polygon` was
   always null → synthetic 200 m circle. Meirim polygons are now matched to
   TabaSearch plans by normalized plan number and attached as `plan.polygon`;
   matched plans render/zoom/highlight with real boundaries (circle remains
   the fallback for unmatched plans). Meirim polygons >1.5 km from the site
   are dropped, unmatched ones render as a dashed context layer with working
   popups (they were `interactive: false` before, so popups never opened).
   Cached `taba_index.json` files are versioned (`version: 2`) so stale
   pre-polygon indexes are ignored.
3. `config.json` contains a real residential address — replace with a landmark.

## Convergence surface (what tighter Cuboid Studio integration means)

The `data` payload already carries everything structured (site_center, radius,
elevation, buildings with per-feature height+source, streets, trees,
institutions, registration, transit, demographics with citations, TABA plan
list + Meirim polygons) — Cuboid Studio currently uses none of it beyond the
broken toast. In order of value:

1. Consume `POST /analyze` JSON directly (skip postMessage fragility entirely).
2. Fix the relay + lock targetOrigin (if the iframe UX stays).
3. Expose SVG/OBJ exports as server endpoints so Cuboid Studio can pull real
   site geometry (streets/buildings) into the 3D scene or Grasshopper.
4. Parameterize analysis radius; honor client lat/lon.
5. Wrap the four fatal layers (geocode/buildings/trees/streets) so failures
   degrade to partial results instead of a 500 — prerequisite for any non-TLV
   demo.
6. Cache the heavy layers (esp. the CBS boundary download).
